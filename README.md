# Sfiral-Duplex-Seasons-3D

Интерактивный 3D-визуализатор годового цикла времён года на базе открытой зеркально-антисимметричной топологии **«Сфираль»** (Three.js, `OrbitControls`, `UnrealBloomPass`).

## Режимы работы

* **Одна Сфираль** — деление модели на 4 фазы: **1. Зима** (первый большой виток), **2. Весна** (первый полувиток S-петли), **3. Лето** (второй большой виток), **4. Осень** (второй полувиток S-петли).
* **Сфираль-дюплекс** — две взаимно перпендикулярные Сфирали с непрерывным потоком по гладкой кривой и переходом через центральный узел.
